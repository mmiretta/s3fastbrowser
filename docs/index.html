S3FastBrowser is a fast, self-hosted web browser for S3-compatible object storage. Browse, search, preview, upload and manage objects on AWS S3, MinIO, Ceph, StorageGRID or any other S3 endpoint.

Get started View on GitHub

Features

Any S3 endpoint

Path-style or virtual-hosted addressing, any region, bucket-scoped keys, recent connections.

Fast browsing

Native S3 pagination: only the current folder is listed, however large the bucket is.

Pluggable previews

Images, PDF, video, audio, text, code, JSON, CSV, Excel, HTML and more. Add your own plugin in a few lines.

Uploads and downloads

Drag and drop files and folders; download selections and folders as a streamed ZIP.

Versions

Version history, delete markers, restore deleted objects, permanent delete.

Bucket settings

Edit bucket policies and lifecycle rules; create presigned links with a chosen lifetime.

Secure by default

Built-in login, endpoint allowlist, credentials kept server-side, localhost binding, strict CSP.

One container, offline

No database, no CDN: every asset is bundled. MIT licensed.

Previews and tools

All screenshots come from the built-in demo; every bucket and file in them is generated. See every preview type.

Get started

Try the demo (a local MinIO with sample files), then run your own instance:

git clone https://github.com/mmiretta/s3fastbrowser.git
cd s3fastbrowser

# demo on http://127.0.0.1:5002 (user demo / password demo)
docker compose --profile demo up -d --build s3fastbrowser-demo

# your instance on http://127.0.0.1:5001
cp .env.example .env      # set SECRET_KEY and S3FB_AUTH_PASSWORD
docker compose up -d --build
